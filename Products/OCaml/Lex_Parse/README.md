# What's this
字句解析(Lexing)、構文解析(Parsing)アルゴリズムを一般の文法に対して適用した汎用構文解析ファンクタ。

バックトラックありLL(0)構文解析、LL(1)構文解析、LR(1)構文解析、SLR(1)構文解析に対応しています。各モジュールの詳細な使い方は ll_parser.ml, lr_parser.ml 内の定義や main.ml を参考にしてください。

main.ml 内のプログラムは、文法の定義などが膨大ですが、それをファンクタに与えて構文解析モジュールを作れば、モジュール内の操作についてはシンプルです。


# 実行方法
ocamlc および dune パッケージが必要です。
dune exec lex_parse で実行できます

dune を使用しない場合は各ファイルを順にコンパイルする必要があります。


# 改善目標
- 入力をファイル、出力をプログラム、のようにしたい。
- 長いトークン(文字列)の処理に対応していない(Lexing-modeの仕組みが)
- main.ml ないからわかるように、構文にマッチしたときにトークン列から構文偽を作成する関数をすべて明示的に与えなければいけなく、文法定義が巨大になる。
