# What's this
命題論理式の解釈器を C# で作成しました。



# 実行方法
.NET ランタイムが必要(のはず)です
VisualStudioからプロジェクトを開いて実行するか、もしくは、コマンドラインでプロジェクト内のディレクトリに入って 
dotnet run
で実行できます。

初めに命題論理式、変数の数、変数１の変数名，変数１の値、変数２の変数名、変数２の値... の順に入力します

最終出力の１つ目は解釈に成功したかどうかのBool値で、２つ目は最初の入力の式内の変数に各変数の値を代入した結果のBool値です。


二項演算子  & と | と → 
単項演算子 !
定数 true と false
変数 (空白を含まないその他の文字列)

で構成された式を入力できます。



# 改善目標
- 簡単のために論理含意を１文字の記号 → で表している。
- 構文解析などを学習する前に自作したものなので、構造設計や命名規則はもう少しわかりやすくできる。
